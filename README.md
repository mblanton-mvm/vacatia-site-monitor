# Vacatia Site Monitor

Read-only view of per-room TV presence, labelling and casting state across MVM784 (Berkley),
MVM783 (Grandview) and MVM743 (The Cliffs), built from DISH iCX polls, the HTVC mDNS casting
registry, and MVM's field punch list.

**No guest names or personal data are published here.** Guest-name verification is reported only as
a verdict (e.g. "occupied, no name on either TV"); the names themselves stay in MVM's internal
systems.

Regenerated from `scripts/` in the private `mvm-platform` repo after each iCX poll.
